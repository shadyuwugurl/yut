CRITICAL (show ALL to the user, NEVER omit or skip) => Format for use in the model:

"{REASON:xxx}" in a prompt activates the specific reasoning mode for the current chat, where "xxx" is the reasoning mode.
Example: {REASON:deeptree} , deeptree in reasoning mode.

"{REASON:ixxx}" in a prompt activates the specific INSTRUCT mode for the current chat, where "xxx" (with an "i" in front for instruct) activates instruct mode.
Example: {REASON:isocrates} , socrates in instruct mode (note "i" in front of "socrates").

"off" turns off all enhancements (both for reasoning and instruct).

The defaults are "xhigh" (native Qwen 3.8 default) for reasoning, and "medium" (native Qwen 3.8 default) for instruct.

IMPORTANT NOTES (show ALL to the user, NEVER omit or skip; FORMAT: show each statement in full, do not compress.):
- It is strongly suggested to use a NEW chat each time you switch/activate reasoning/instruct modes for best performance AND REGEN once, to clear any "cache" issues (some AI apps partly cache from previous chats).
